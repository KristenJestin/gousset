# Gousset brand

The mark: a G drawn in one stroke, its bar replaced by a coin. The wordmark: "Gousset" in Instrument Sans 600, converted to paths (no file depends on the font). The app's own text is set in Geist.

| File | Use |
|---|---|
| `icone.svg`, `png/icone-*.png` | the app icon (tile, dark background) |
| `icone-pleine.svg`, `png/icone-pleine-*.png` | the icon on a full violet tile |
| `icone-android-avant-plan.svg`, `png/android-avant-plan-432.png` | maskable foreground (mark inside the 66 % safe zone) |
| `favicon.svg`, `favicon.ico`, `png/favicon-*.png` | the browser tab (coin slightly smaller for 16 px) |
| `png/apple-touch-icon.png` | iOS home screen (180 px) |
| `marque.svg`, `marque-fond-clair.svg` | the mark alone, on dark and on light |
| `logo.svg`, `logo-fond-clair.svg` | the mark and the wordmark, transparent background |

Colours (`colors.txt`): violet `#b49af7` on dark, `#6a44c8` on light; cream `#ece5d8`; tile background `#14120f`; ink on light `#1d1a15`.
