What changes

  • Four columns instead of seven. The file's name first (14 px, medium, the text colour), its facts under it (format · account · period, 12 px, soft); then New and Already known right-aligned in fixed widths, so the numbers line up from file to file; then the state. The wireframe's order is kept, left to right.
  • A long name keeps its end. The start gives way with an ellipsis; the last part (dates, extension), which is what tells two statements apart, stays. The whole name is in the tooltip and for screen readers.
  • State chips: colour only where something waits for you (violet: Account to choose, Columns to confirm) or something failed (red). Imported is a quiet grey chip with a green check; Reading and Saving carry the loader; Undone is outlined.
  • The account question is one inset line, aligned with the name: the sentence, the select (240 px) and the button on one line. The sentence is the visible label; the select is named “Account of <file>” for screen readers. No empty gap.
  • The summary: the four counts as one group (16 px semibold, their label under them in 12 px), the actions at the right edge. Go to the review is the primary button, last. Undo this import is a quiet button with its icon, set apart by a wider gap: it turns red only on hover.
  • One primary at a time. Older imports fold back to their row (the chevron opens their summary again); only the newest stays open.
  • The drop zone is one row (72 px) instead of a tall box; on drag-over its edge and tile turn violet.
  • Phone: no drag and drop, so the zone is a Choose files button; each file is a stack (name on two lines at most, facts, chip and counts); the actions are full width, the primary on top.

Rejected

  • Keeping seven columns. Between 1024 and 1280 px, the long names and “1 Jan. 2016 to 31 Oct. 2026” wrap: the reported “labels wrapping”.
  • Truncating names at the end: every export of one bank starts the same way.
  • “Go to the review” as an underlined link: it is the next step, so it is a button.
  • Undo as a bordered button beside the primary: the same weight as the way forward (#125). Undo in a ⋯ menu: it hides a recovery the user needs right after a mistake.
  • A green “Imported” chip: a list of six green chips is noise, and green already means income.
  • A page-level “Continue” bar under the list: it repeated the newest summary.
