What changes

  • No invented figure, name or chart, for any user: the made-up household stays in the fixtures, for tests and Storybook only.
  • One block says what the review will be: its four parts, each with the colour it will keep (income, spent, set aside, left), in words only. No grey chart pretending to load: a skeleton promises data that is not coming.
  • It points to what works today: Accounts, Import, Operations, with the user's own counts at the right. A new user sees Import your first statement first, in the accent; the counts say “None yet”.
  • The block takes the page's width, as the other pages' blocks do; the four parts on one row.
  • The page keeps its place in the navigation: the review stays the first tab, so nothing moves when it arrives in 0.4.
  • The MCP month tool answers the same, in text, with no figure:

The monthly review is not available yet: it comes in a later version of Gousset. Your accounts and lines are: call accounts {"action": "list"} for the balances, or lines {"action": "list", "account": "Current account"} for the lines.

Rejected

  • Hiding the review until 0.4: the first tab would change later, and the user would not know it is coming.
  • A rough review from the lines (totals in and out per month): a half review, with no subjects, that would contradict the real one once it lands.
  • An illustration: the app has none elsewhere; the four colours say enough.
